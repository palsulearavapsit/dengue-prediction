About the System

The Dengue Outbreak Prediction System combines historical dengue surveillance, weather/environmental information, geographic information, temporal patterns, district-level dengue lag features, and machine learning to estimate dengue activity for the next observed district-level report.

Current supported location: Pune, Maharashtra, India

Current model: RandomForest_log1p

Current target: next_observed_report_cases

This system is a prototype decision-support tool and is not intended to replace official dengue surveillance, epidemiological assessment, laboratory diagnosis, or medical advice.
